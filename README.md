# Perfect Weather Map

An interactive global climate atlas for exploring where and when weather matches your personal definition of a perfect day.

## Live app

https://perfect-weather-map.ollierobb29.chatgpt.site

## Features

- Perfect-weather day counts based on temperature, dew point, wind, cloud cover, and a selected month range
- Average daily high-temperature heatmap mode
- 1° display tiles from a 5° source grid
- Infinite horizontal map, globe view, pinch/scroll zoom, country outlines, and progressive country-capital labels
- Greyed ocean, Antarctica, and unavailable-data cells

## Data

The atlas uses daily Open-Meteo / ERA5 climate data when the downloaded binary atlas is available. If that large archive is unavailable, the app clearly switches to a smooth climatological preview model. The displayed capital labels are limited to sovereign-country capitals.
